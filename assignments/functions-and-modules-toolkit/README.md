# 📘 Assignment: Functions and Modules Toolkit

## 🎯 Objective

Practice writing reusable Python functions and organizing them in a simple module so your code is easier to read and maintain.

## 📝 Tasks

### 🛠️ Create Reusable Functions

#### Description
Write a few small functions that solve simple tasks and return useful results.

#### Requirements
Completed program should:

- Define at least two functions with clear names.
- Use parameters and return values instead of repeating code.
- Test each function with a few example calls.

### 🛠️ Import and Use a Module

#### Description
Place your functions in a separate Python file and import them into a main program.

#### Requirements
Completed program should:

- Store functions in a file such as `helpers.py`.
- Import the functions into a main script.
- Call the functions to produce a complete example output.
